# ソロ会議 (SoloMeet)

自分との作戦会議を楽しむ、落ち着いたカフェテーマの習慣化アプリ。

## 🎯 コンセプト

- **爆速起動**：スプラッシュ画面なし、起動時に最優先の「問いかけ」を中央に表示
- **対話型UI**：カップをタップして進捗を報告するダイアログ形式
- **コーヒーをモチーフ**：進捗がカップの液体として可視化される
- **豆知識アンロック**：タスク完了時にコーヒー関連の知識を獲得

## 📁 プロジェクト構造

```
soloMeet/
├── SoloMeetApp.swift          # アプリエントリーポイント
├── Models/
│   ├── Task.swift             # 習慣タスクモデル
│   ├── MeetingLog.swift        # 完了ログモデル
│   ├── UserProfile.swift       # ユーザー情報モデル
│   └── CoffeeTip.swift         # 豆知識モデル
├── Views/
│   ├── ContentView.swift       # メイン画面（コーヒーカップUI）
│   └── ProgressDialogView.swift # 進捗報告ダイアログ
├── Theme/
│   └── Colors.swift            # カラーパレット定義
├── Utils/
│   └── Extensions.swift        # 便利拡張機能
└── Info.plist                  # アプリ設定ファイル
```

## 🔧 使用方法（Xcodeでのセットアップ）

### 1. Xcode 15以上で新しいSwiftUIプロジェクトを作成

```bash
# 既存のgitリポジトリからファイルをコピー
cp -r soloMeet/* /path/to/your/xcode/project/
```

### 2. 必要なフレームワークの確認

- iOS 17.0以上
- SwiftUI
- SwiftData
- Combine（必要に応じて）

### 3. ビルド設定

1. Xcodeで `SoloMeetApp.swift` をターゲットメンバーシップで主アプリに追加
2. Info.plistをプロジェクト設定に統合
3. Bundle Identifierを設定 (例: com.yourcompany.solomeet)

- **朝（6時-12時）**: 浅く明るいトーン

- **夜（18時-6時）**: 深く落ち着いたトーン

## 🔄 データフロー

1. **起動時**：UserProfileから前回の失敗理由を読み込み
2. **タスク選択**：tasksのリストから最優先を表示
3. **進捗報告**：ProgressDialogで成否を入力
4. **ログ保存**：MeetingLogに結果を記録、進捗を更新
5. **豆知識解除**：完了時にCoffeeTipをアンロック

## 💾 SwiftData永続化

アプリはSwiftDataを使用して以下をローカルに保存：
- ユーザーのタスク進捗
- 日次の完了ログ
- アンロック済みの豆知識
- ユーザープロフィール

初回起動時にサンプルデータが自動注入されます。
